# Sejtbiológia gyakorló

Sejt molekuláris biológiája és genetikája I – 417 gyakorlókérdés magyarázattal, telepíthető webapp (PWA).

**Élő verzió:** https://fbalazs720000.github.io/sejtbiosz/

- offline működik (service worker)
- telepíthető a kezdőképernyőre (Android: Chrome → Alkalmazás telepítése; iPhone: Safari → Megosztás → Hozzáadás a főképernyőhöz)
- XP, szintek, combo, napi cél, elsajátítottság-követés, jelvények
- a haladás a saját böngésződben marad (localStorage), sehova nem kerül fel
